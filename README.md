# 2026 年天猫四店日报商品分析

这个 Streamlit 项目会自动读取财务上传页导入到服务器的四家店铺日报：

- `2026年天猫日报表-易丽洁...`
- `2026年坐拥宁静日报表...`
- `2026年国货严选日报表...`
- `2026年咖时光日报表-天猫...`

应用先按店铺区分，再按日期 Sheet 和商品 ID 汇总销量、订单量、盈亏。同一商品 ID 不会跨店合并。财务上传页导入日报后，页面会根据服务器文件修改时间与大小自动更新。支持 `.xls`、`.xlsx` 和 `.xlsm`。

当前统计口径从 `2026-07-01`（含）开始，日期更早的 Sheet 在解析入口直接跳过。

解析器保留了咖时光早期模板的安全兼容能力，不会把整店盈亏错误归到第一件商品；但按当前日期口径，7 月前的这些 Sheet 会直接跳过，不进入看板。

聚合后的读表结果会缓存在项目 `.cache/` 目录（服务器可通过 `TMALL_CACHE_DIR` 指定独立目录）。缓存键包含解析版本、文件路径、大小、修改时间和文件内容哈希；Excel不变时直接读取缓存，内容变化时自动重建并清理该文件的旧缓存。

## 财务上传页

服务器提供独立上传地址：`http://150.158.133.102:8080/upload/`。主看板和上传页保持公开。财务可以按店铺选择一个或多个工作簿；系统会先完整解析校验，再原子替换服务器 `data/` 中的正式文件，并把旧版本归档到 `data/archive/店铺/`。业务文件和上传历史都不会进入 Git 仓库。

## 启动

本项目目录已准备好运行环境时，直接执行：

```powershell
.\start_dashboard.ps1
```

也可以使用等价命令：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

如果需要在另一台电脑上重新创建环境，在 PowerShell 中进入本目录后执行：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

如果本机没有 `py` 命令，可把第一行替换为可用 Python 的完整路径。启动后浏览器通常会自动打开 `http://localhost:8501`。

## 数据口径

- 销量取标题为“数量”的列。
- 订单量取标题为“订单数”的列，并在销量趋势图中以橙色虚线展示。
- 商品盈亏取标题为“单品结余”的列。
- 商品 ID 处于合并区域时，合并区域内每个明细行的销量与盈亏都归入该商品。
- 项目启动时会自动检查 `8.13 / 655468070181`：销量必须为 `20`，盈亏必须为 `22.015`。
- 缺失商品日期补零后计算日增减；前一日为零时，百分比环比留空，避免无穷大。
